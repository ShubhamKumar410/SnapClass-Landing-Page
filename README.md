# SnapClass – AI-Powered Attendance System

SnapClass is an AI-powered attendance management platform designed to simplify classroom attendance tracking. This project features a responsive landing page built using **HTML, CSS, JavaScript, and Flask**, showcasing its key features and user workflows.

## Tech Stack
- HTML, CSS, JavaScript
- Python (Flask)

## Features
- Responsive landing page
- Modern and user-friendly interface
- Overview of student and teacher workflows
